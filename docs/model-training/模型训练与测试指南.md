## 1. 快速开始（Network A · MNIST）

在仓库根目录，Python 使用 `.venv`：

```powershell
# 1) 训练
.\.venv\Scripts\python.exe -m model_training.network_a.train --device cuda

# 2) 取最新 run
$run = Get-ChildItem model_training\outputs | Sort-Object Name -Descending | Select-Object -First 1

# 3) 全量测试（10k 官方测试集，更新 metrics + full_test_report.json）
.\.venv\Scripts\python.exe -m model_training.network_a.evaluate --run-dir $run.FullName --mode full_test

# 4) 导出 → 注册
.\.venv\Scripts\python.exe -m model_training.network_a.export_weights --run-dir $run.FullName
.\.venv\Scripts\python.exe -m model_training.network_a.register_backend --weights-dir $run.FullName

# 5) 分项验收（fixed / bounds / layerwise / ahe）
.\.venv\Scripts\python.exe -m model_training.network_a.evaluate --run-dir $run.FullName --mode all --model-id cnn-mnist-trained
```

**统一入口（仅训练）**：`python model_training/run.py --task network-a --device cuda`

## 4. Network A 详解

### 4.1 拓扑与定点流水线

固定卷积核 `[[1,0,1],[2,0,2],[1,0,1]]` + 可训 FC（64→16→10，1210 参数）。

```
uint8 → per-image min-max → int32(32×32)
→ 固定 conv → ReLU（客户端）
→ sum-pool 4×4 × (1/16)₁₀bit
→ shift（after_pool，from_bits=26 → 16）
→ FC₁ → ReLU + shift（after_fc1，from_bits=32 → 16）
→ FC₂ → ReLU
```

**截断本征尺度（不可随意改小）**：

| 检查点 | client_action | from_bits | shift_bits |
|--------|---------------|-----------|------------|
| after_pool | shift | 26 | 26 |
| after_fc1 | relu_then_shift | 32 | 32 |

实现：`model_training/network_a/truncation_config.py`；WS 协议：`vpin-backend/.../topology.py`。

> **历史坑**：旧版校准曾把 shift 降到 24/30，会错误缩放实数、拉低精度。现已固定 **26/32**；批次扫描仅做安全验证（见 §4.6）。

### 4.2 训练流程

`train.py` 两阶段：

1. **Float 预热**（默认 30 epoch，AdamW + cosine）
2. **截断校准** → 写 `truncation_config.json`
3. **定点 QAT**（若 float 权重直接 fixed 推理未达 target，默认 20 epoch）
4. QAT 未达标 → **恢复 `checkpoint_float.pt`**，保留 float 权重

产物目录：`model_training/outputs/<UTC_timestamp>/`

| 文件 | 含义 |
|------|------|
| `checkpoint.pt` / `checkpoint_float.pt` | 模型 state_dict + plan |
| `truncation_config.json` | shift 26/32 + 校准统计 |
| `metrics.json` | 训练阶段指标 + `evaluation` 全量测试结果 |
| `weight_fc1_64_16.npy` 等 4 个 npy | AHE 部署权重 |
| `full_test_report.json` | **全量 10k 测试报告**（`--mode full_test` 生成） |
| `evaluation_report.json` | fixed/bounds/layerwise/ahe 分项报告 |

### 4.3 全量测试（必做）

对官方 MNIST **全部 10,000 张测试集**评估 float 与 fixed 精度：

```powershell
.\.venv\Scripts\python.exe -m model_training.network_a.evaluate --run-dir $run --mode full_test
```

输出 `full_test_report.json`，并回写 `metrics.json` 的 `evaluation` 与 `phases.*.best_test_acc`。

**单样本调试**（Python）：

```python
from vpin_client.data.preprocess import load_mnist_test
import torch
from model_training.network_a.evaluate import _load_model

run_dir = Path("model_training/outputs/20260622_184254")
model, plan = _load_model(run_dir)
prep = load_mnist_test(9888)  # 任意 test index 0..9999
img = torch.from_numpy(prep.raw_uint8).unsqueeze(0).unsqueeze(0)
with torch.no_grad():
    pred = int(model.forward_fixed_point(img, plan=plan).argmax(dim=1).item())
print(prep.label, pred)
```

### 4.4 分项评估模式

```powershell
.\.venv\Scripts\python.exe -m model_training.network_a.evaluate --run-dir $run --mode <mode>
```

| mode | 内容 | 通过条件 |
|------|------|----------|
| `full_test` | 10k float + fixed + 逐类精度 | fixed ≥ 90% |
| `fixed` | 同 full_test 的 fixed 路径（loader） | ≥ 90% |
| `layerwise` | Torch 定点 vs homomorphic 明文，逐层 max diff | max_diff = 0 |
| `bounds` | 500 张激活幅度 vs BSGS / int32 上限 | 无超限 |
| `ahe` | WS 同态 vs 明文定点（需后端，默认 50 张） | pred_mismatches=0 |
| `feasibility` | 部署门禁综合报告 | deployable |
| `all` | 以上（不含 full_test） | 分项打印 |

自检（不依赖 run）：`python -m model_training.network_a.verify`

### 4.5 AHE 端到端测试

```powershell
# 终端 1 — 后端（勿用裸 uvicorn）
cd vpin-backend
..\.venv\Scripts\python.exe -m vpin_backend.main

# 终端 2 — 单样本
cd vpin-client
..\.venv\Scripts\python.exe -m vpin_client.cli ahe-infer --model cnn-mnist-trained --mnist-index 0 --timing

# E2E smoke（明文定点 logits vs AHE 逐元素一致）
..\.venv\Scripts\python.exe scripts\ahe_e2e_smoke.py --model cnn-mnist-trained --mnist-index 0
```

单次 AHE 推理约 40–50s（CPU 椭圆曲线）。全量 10k 不推荐（极慢）。

**parity 与分类精度正交**：layerwise=0 + AHE logits 一致 ≠ 高分类准确率。

### 4.6 截断与安全边界

- **shift 前**：对比 BSGS 解密上限 `(3.2×10⁶)²`
- **shift 后**（重加密前）：对比 int32 上限 `2³¹-1`
- 校准代码：`train.py::_calibrate_plan` → `batch_calibrate_shifts`

若新 run 的 shift 与 `topology.py` 不一致：

```powershell
.\.venv\Scripts\python.exe -m model_training.network_a.sync_topology --run-dir $run
# 改 topology 后需重启后端
```

## 7. 验收标准汇总

| 层级 | 检查项 | 命令/产物 |
|------|--------|-----------|
| 实现正确性 | layerwise max_diff = 0 | `evaluate --mode layerwise` |
| 同态一致 | AHE pred = 明文定点 pred | `evaluate --mode ahe` / `ahe_e2e_smoke.py` |
| 分类性能 | fixed acc ≥ 90%（Network A） | `evaluate --mode full_test` |
| 安全边界 | 激活未超 BSGS/int32 限 | `evaluate --mode bounds` |
| 部署 | registry + WS 加载权重 | `register_backend` + `ahe-infer` |

---

## 8. 故障排查

```
verify 失败           → 环境/依赖/MNIST 下载
layerwise ≠ 0         → 定点实现与 homomorphic 明文不一致（实现 bug）
AHE mismatches > 0    → 后端权重/拓扑/session 未对齐；重启 backend
fixed 低但 layerwise=0 → 权重未适应定点截断；需 QAT/蒸馏（非 AHE bug）
bounds 失败           → FC 激活过大；考虑权重正则或 shift 校准
metrics 与 full_test 不一致 → 以 full_test_report.json 为准，重跑 full_test
```
