# MVP-AHE 环境配置与手动步骤

本文档列出 **无法一键脚本自动化** 的操作。可自动化的部分请用仓库脚本：

| 脚本 | 作用 |
|------|------|
| `scripts/setup.ps1` | 首次：venv + pip + npm + Rust 检查 |
| `scripts/check-env.ps1` | 部署前预检（BSGS、权重、端口、二进制） |
| `scripts/generate-bsgs-pickle.ps1` | 生成 Python 用 `table.pickle`（~30 分钟） |
| `scripts/build-rust-ahe.ps1` | 编译 `ahe-cli` / `ahe-server`（stable） |
| `scripts/start-rust-ahe.ps1` | 启动 Rust server :8001 / :8002 |
| `scripts/run_ahe_triple_test.ps1` | 三引擎对照测试 |
| `start-ahe.ps1` | 一键 Python 后端 + Tauri |
| `.env.example` | 环境变量模板（复制为 `.env` 可选） |

主流程见 [`MVP-AHE-部署指南.md`](../MVP-AHE-部署指南.md)。

---

## 1. 系统级安装（必须手动）

### 1.1 Python 3.10+

- 下载：https://www.python.org/downloads/
- 安装时勾选 **Add Python to PATH**
- 验证：`python --version`

### 1.2 Node.js 18+

- 下载：https://nodejs.org/
- 验证：`node --version`、`npm --version`

### 1.3 Rust（stable，AHE + Tauri）

```powershell
rustup default stable
rustc --version
```

- **AHE**：`vpin-client`、`vpin-backend` 使用 **stable**
- **CP-SNARK**：见 §4，需 **nightly-2023-06-26**

### 1.4 Visual Studio Build Tools（Windows，Tauri 必需）

安装 [VS Build Tools](https://visualstudio.microsoft.com/visual-cpp-build-tools/)，工作负载 **使用 C++ 的桌面开发**。

### 1.5 WebView2

Windows 10/11 通常已带；白屏时安装 [WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)。

### 1.6 Git / SSH

推送到 GitHub 需 SSH 或 HTTPS 凭据。`table.bin`（~208MB）超过 GitHub 100MB 限制，**不得提交**。

## 2. 环境变量（可选）

```powershell
copy .env.example .env
```

| 变量 | 何时手动设 |
|------|------------|
| `VPIN_REPO_ROOT` | 非标准 clone 路径 |
| `VPIN_BSGS_TABLE` | BSGS 表非默认位置 |
| `VPIN_CLIENT_ROOT` | 旧 layout sibling platform |

> `AHE_CRYPTO_BACKEND` **不由 server 读取**；CLI 用 `--crypto-backend ark|ec`。

---

## 3. BSGS 预计算表

### 3.1 Python `table.pickle`（可脚本，~30 分钟）

```powershell
.\scripts\generate-bsgs-pickle.ps1
```

生成 `src/Pre_computed_table/table.pickle`，Python 路线必需，已 `.gitignore`。

### 3.2 Rust `table.bin`（必须手动拷贝）

**不进 Git**（体积 + GitHub 限制）。按优先级查找：

1. `vpin-client/tests/fixtures/table.bin`
2. `src/Pre_computed_table/table.bin`
3. `../vpin-platform/tests/fixtures/table.bin`

**手动**：从开发机或 sibling platform **拷贝**有效文件。无 pickle→bin 一键脚本。损坏文件会导致 `discrete log not found`。

验证：

```powershell
.\scripts\check-env.ps1 -RequireBsgsBin -RequireRust
```

## 4. CP-SNARK（可选，nightly 工具链）

```powershell
rustup toolchain install nightly-2023-06-26
cd src\cp-snark-full
rustup run nightly-2023-06-26 cargo build
```

与 AHE stable 栈独立，需人工切换工具链。

---

## 5. MNIST（首次需联网）

自动下载到 `model_training/data/MNIST/raw/`（`.gitignore`）。

内网：在可联网机器下载后 **整目录拷贝** 到目标机。

---

## 6. 编译产物路径

| 二进制 | 输出 |
|--------|------|
| `ahe-cli` | `vpin-client/target/release/ahe-cli.exe` |
| `ahe-server` | `vpin-backend/target/release/ahe-server.exe` |

`target/` 不提交；换机器运行 `scripts/build-rust-ahe.ps1`。

---

## 7. 三引擎启动

1. `.\scripts\check-env.ps1`
2. `.\start-ahe.ps1`（Python :8000 + Tauri）
3. 另终端 `.\scripts\start-rust-ahe.ps1 -Both`（Rust :8001/:8002）
