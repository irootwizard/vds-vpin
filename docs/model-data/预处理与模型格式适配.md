## 1. 预处理单源（摘要）

> 外部平台格式对照见 [数据集格式与上传规范.md](./数据集格式与上传规范.md)。

| 层级 | 路径 | 用途 |
|------|------|------|
| **常量 SSOT** | `vpin-client/vpin_client/data/constants.py` | `PAD_SIZE=32`, `FIXED_POINT_BITS=16`, clip 范围 |
| **核心流水线** | `vpin-client/vpin_client/data/core.py` | `preprocess_uint8_28x28`, `preprocess_result_to_dict` |
| **官方 MNIST** | `vpin-client/vpin_client/data/official.py` | 客户端本地加载 + 预处理 |
| **上传图片** | `vpin-client/vpin_client/data/upload.py` | PNG/JPEG → 28×28 → 定点 |
| **兼容门面** | `vpin-client/vpin_client/data/preprocess.py` | CLI、AHE、Tauri 向后兼容 |
| **服务端官方** | `vpin-backend/vpin_backend/data/official.py` | HTTP 官方 MNIST 预处理 |
| **服务端上传** | `vpin-backend/vpin_backend/data/upload.py` | 上传存储 `data/uploads/{uuid}/` |
| **训练镜像（Torch）** | `model_training/network_*/preprocess.py` | batch 前向，与 client 逐图语义一致 |
| **MNIST 数据** | `vpin-client/vpin_client/data/official_mnist.py` | 官方 idx，缓存 `model_training/data/mnist/` |

**禁止**用于 AHE 验收：`scripts/prepare_mnist_network_a.py`、`vpin-backend/data/mnist/*.npy`、`src/cnn_networks/image_mnist_32_32.npy`。

### 预处理流水线（每张图独立）

```
uint8 (28×28) → /255 → pad 32×32 → per-image min-max → ×2^16 → int32
```

与论文 legacy `Client.py` 一致（单图 min-max，非 batch 全局）。

## 2. 模型权重格式（摘要）

> 完整 schema、外部平台对照表见 [模型权重格式规范.md](./模型权重格式规范.md)。

### 2.1 AHE 推理（当前已打通）

| 格式 | 说明 | 消费者 |
|------|------|--------|
| **npy bundle** | 4 个文件，命名随网络见下表 | `homomorphic_network_a.py`, WS `session.py` |
| **registry** | `vpin-backend/data/models/registry.json` 字段 `weights_dir` | ModelSelect → 加载 npy |

**Network A–E npy 文件名**（`vpin_client/models/weights_layout.py`）：

| 网络 | weight_fc1 | bias_fc1 | weight_fc2 | bias_fc2 | pool |
|------|------------|----------|------------|----------|------|
| A | `weight_fc1_64_16.npy` | `bias_fc1_16.npy` | `weight_fc2_16_10.npy` | `bias_fc2_10.npy` | 4×4 s4 |
| B | `weight_fc1_64_32.npy` | `bias_fc1_32.npy` | `weight_fc2_32_10.npy` | `bias_fc2_10.npy` | 4×4 s4 |
| C–E | `*_256_*` 等 | … | … | … | 2×2 s2 |

训练导出：`model_training/network_a/export_weights.py`、`network_b/export_weights.py`。

### 2.2 CP-SNARK / 注册上传

| 格式 | 说明 |
|------|------|
| **model_export.json** | `conv_filter_flat`, `pool`, `fc[]` — POST `/api/v1/models` 字段 `weights` |
| **manifest.json** | 可选元数据 |

### 2.3 不支持直接 AHE 的格式

| 格式 | 处理 |
|------|------|
| `.onnx` / `.pth` / `.h5` | 需先训练栈导出为 npy bundle |
| 单文件 `.npy` | 不完整，需整包 |

检测工具：`vpin_client/models/format_adapter.py` → `detect_format()`。

## 3. 双端预处理 API

| 场景 | 客户端 | 服务端 HTTP |
|------|--------|-------------|
| 官方 MNIST 单张 | `load_official_test(i)` / Tauri `ahe_preprocess` | `GET /api/v1/data/official/test/{index}` |
| 官方 MNIST 批量 | `official_batch_to_dict` / `ahePreprocessBatch` | `GET /api/v1/data/official/batch?start=&count=` |
| 上传图片 | `preprocess_upload_bytes` / Tauri `preprocess_upload_file` | `POST /api/v1/data/upload/preprocess` (multipart) |
| 上传记录 | — | `GET /api/v1/data/upload/{id}`, `GET /api/v1/data/uploads` |

**遗留别名**（仍可用）：`GET /api/v1/demo/ahe-preprocess*` → 同上官方接口。

前端封装：`src/services/dataApi.js`（数据）、`src/services/aheClient.js`（AHE 推理）。

## 4. 前端上传

| 组件 | 行为 |
|------|------|
| `ModelWarehouseView.vue` | `GET /models` 列表 + 上传 modal |
| `vpinApi.js` | `uploadModel()` — `.zip` → `npy_bundle`，`.json` → `weights` |
| `AheDemoView.vue` | 官方 MNIST 预览 + 上传预处理；AHE 推理暂仅官方序号 |
| `dataApi.js` | `uploadAndPreprocess`, `fetchOfficialBatch` |

**后端** `POST /api/v1/models` 表单：

- `model_id`, `name`, `network`（A–E）
- `npy_bundle`：zip 含 4×npy → 解压到 `uploads/{id}/npy/`，写入 registry `weights_dir`
- `weights`：model_export.json（CP-SNARK 路径）

## 5. 截断算法（解密精度）

- 本征尺度：**shift_pool=26**, **shift_fc1=32**（`from_bits`，非任意截断量）
- 批次校准：扫描 N 张官方 MNIST，验证 BSGS / int32 安全，**不修改** from_bits
- 详见 [network-a-批次截断算法设计.md](./network-a-批次截断算法设计.md)

## 6. 训练与同态测试命令

```powershell
# Network A
.\.venv\Scripts\python.exe -m model_training.network_a.train --device cuda
.\.venv\Scripts\python.exe -m model_training.network_a.export_weights --run-dir model_training\outputs\<id>
.\.venv\Scripts\python.exe -m model_training.network_a.register_backend --weights-dir ...

# Network B（AHE 拓扑已支持，pool/conv 同 A）
.\.venv\Scripts\python.exe -m model_training.network_b.train --device cuda

# E2E
.\.venv\Scripts\python.exe scripts\ahe_e2e_smoke.py --model cnn-mnist-trained --mnist-index 0
```

**AHE 已支持网络**：A、B（C–E 需扩展 `topology.py` + 2×2 pool 引擎）。
