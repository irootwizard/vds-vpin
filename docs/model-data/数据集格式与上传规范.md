## 1. vPIN 标准输入契约（Canonical）

无论数据来自何处，进入 Network A–E 同态/定点流水线前，必须收敛为下列语义：

| 阶段 | 类型 | 形状 | 值域 / 说明 |
|------|------|------|-------------|
| **原始图** | `uint8` | `(28, 28)` | 灰度手写数字，0–255 |
| **归一化前** | `float32` | `(1, 1, 32, 32)` | 28×28 居中 pad 到 32×32，像素 ÷255 |
| **归一化后** | `float32` | `(1, 1, 32, 32)` | **单图** min-max → clip `[0.001, 0.9999999]` |
| **定点输入** | `int32` | `(1, 1, 32, 32)` | `normalized × 2^16`（`FIXED_POINT_BITS=16`） |
| **会话摘要** | `hex` | 64 字符 | `SHA256(fixed_int32.tobytes())` → `input_digest_hex` |

**关键约束**（与 legacy `Client.py` 一致）：

- 每张图 **独立** min-max，禁止 batch 全局归一化。
- 输入空间为 **28×28 灰度 MNIST 风格**；彩色图会先转灰度再 resize。
- 标签 `label` 为 `0–9` 整数，上传场景可为 `null`（无监督）。

实现入口：

- 核心：`vpin-client/vpin_client/data/core.py` → `preprocess_uint8_28x28`
- 官方 MNIST：`vpin-client/vpin_client/data/official.py`
- 上传：`vpin-client/vpin_client/data/upload.py`

## 2. 当前已打通的上传方式

### 2.1 HTTP 单图上传（浏览器 / API）

| 项 | 说明 |
|----|------|
| **端点** | `POST /api/v1/data/upload/preprocess` |
| **Content-Type** | `multipart/form-data`，字段名 `file` |
| **接受扩展名** | 由 Pillow 解码，实测 **PNG / JPEG / WebP / BMP / GIF** |
| **服务端行为** | 解码 → 转灰度 → LANCZOS resize 28×28 → 标准流水线 → 存 `data/uploads/{uuid}/` |
| **响应字段** | `source`, `upload_id`, `filename`, `input_digest_hex`, `preview_png_base64`, `fixed_shape` |

### 2.2 客户端本地（Tauri / CLI）

| 方式 | 入口 |
|------|------|
| 本地文件 | `preprocess_upload_path(Path)`、`Tauri preprocess_upload_file` |
| 内存字节 | `preprocess_upload_bytes(data, filename=...)` |

### 2.3 官方 MNIST 索引（非上传，但属「数据集」）

| 项 | 说明 |
|----|------|
| **索引范围** | test：`0..9999`；train：`0..59999` |
| **HTTP** | `GET /api/v1/data/official/test/{index}`、`/batch?start=&count=` |
| **磁盘** | `model_training/data/mnist/MNIST/raw/*.idx*-ubyte` |

## 3. 外部平台格式收录

下表按 **「原生支持 / 需转换 / 禁止」** 分类。  
「需转换」表示平台格式合法，但须先变为 **28×28 uint8 单图** 或走官方 MNIST 管线。

### 3.1 总览对照表

| 平台 / 数据集 | 常见原始格式 | vPIN 原生 | 推荐接入路径 |
|---------------|-------------|-----------|--------------|
| **LeCun 官方 MNIST** | IDX `*-ubyte`（gzip） | ✅ | `official_mnist.py` / 官方 API |
| **torchvision.datasets.MNIST** | 同官方 IDX | ✅ | 与上相同（唯一下载源） |
| **Hugging Face `ylecun/mnist`** | Parquet + `Image` 列 + `label` | ⚠️ 需转换 | 见 §4.1 |
| **Hugging Face 通用图像集** | Parquet / 文件夹 PNG / WebDataset | ⚠️ 需转换 | 见 §4.2 |
| **Kaggle Digit Recognizer** | `train.csv`（label + pixel0…783） | ⚠️ 需转换 | 见 §4.3 |
| **Kaggle MNIST as JPEG** | `train/{0..9}/*.jpg` | ⚠️ 需转换 | PNG 上传或批量脚本 |
| **UCI ML Repository** | ARFF / CSV 像素列 | ⚠️ 需转换 | reshape → uint8 |
| **OpenML** | ARFF / 稀疏矩阵 | ⚠️ 需转换 | 导出为 28×28 PNG |
| **TensorFlow Datasets** | `tf.data` / TFRecord | ⚠️ 需转换 | 导出 PNG 或 numpy |
| **NumPy 单文件** | `.npy` `(N,28,28)` 或 `(N,784)` | ⚠️ 需转换 | 见 §4.4 |
| **本仓库废弃缓存** | `vpin-backend/data/mnist/*.npy` | ❌ 禁止 | 勿用于 AHE 验收 |
| **本仓库 legacy** | `src/cnn_networks/image_mnist_32_32.npy` | ❌ 禁止 | 32×32 已 pad，语义不一致 |

## 4. 分平台转换说明

### 4.1 Hugging Face — `ylecun/mnist`（Parquet / Image）

**Hub 结构**（2024 起主流）：

- 配置：`ylecun/mnist`
- 特征：`image`（`dtype: image`，解码为 PIL 28×28 L）、`label`（0–9 class）
- 分片：`train` 60000 / `test` 10000

**实测（2026-06-23，`scripts/analyze_dataset_formats.py`，test index=0）**：

| 对比项 | 官方 IDX | HF datasets-server API |
|--------|----------|-------------------------|
| 像素 mean | 23.54 | 24.69 |
| `input_digest_hex` 一致 | 基准 `369c85c3…` | ❌ `847f4006…` |
| 原因 | 原始 uint8 | API 返回 **JPEG 缓存** URL，有损重编码 |

**结论**：HF Hub 可用于集成演示，但 **AHE 验收须用 `official_mnist.py`**。本地 `datasets` streaming 读 Parquet 无损列时，仍需逐样本核对 digest。

**与 vPIN 差异**：HF 提供的是 **原始 28×28 uint8**（无损路径下），尚未做 pad / per-image min-max / ×2¹⁶。

```python
# 示例：HF → vPIN 单图 uint8（需 pip install datasets pillow）
from datasets import load_dataset
from vpin_client.data.core import preprocess_uint8_28x28
import numpy as np

ds = load_dataset("ylecun/mnist", split="test")
pil_img = ds[0]["image"]  # 28×28 L
raw = np.array(pil_img, dtype=np.uint8)
result = preprocess_uint8_28x28(raw, label=int(ds[0]["label"]), source="upload")
```

### 4.2 Hugging Face — 通用图像数据集

| HF 存储形态 | 说明 | vPIN 处理 |
|-------------|------|-----------|
| **Parquet `image` 列** | `struct{bytes, path}` 或 `dtype: image` | 解码 → 灰度 → resize 28×28 |
| **仓库内 `*.png` / `*.jpg`** | `imagefolder` 或自定义脚本 | 同上传路径 |
| **WebDataset**（`.tar` 分片） | 大规模多模态 | 逐条解码后转 28×28 |
| **metadata.csv + 图片路径** | Hub 图像分类常见布局 | 读路径 → Pillow |

**注意**：非 28×28 数据（CIFAR、ImageNet 等）必须先 **灰度 + resize 28×28**，否则与 Network A 拓扑不兼容；精度与论文设置无关，仅作演示。

### 4.3 Kaggle

#### Digit Recognizer（`train.csv`）

| 列 | 含义 |
|----|------|
| `label` | 0–9 |
| `pixel0` … `pixel783` | 行优先 28×28，0–255 |

```python
import pandas as pd
import numpy as np

df = pd.read_csv("train.csv")
row = df.iloc[0]
raw = row.filter(like="pixel").to_numpy(dtype=np.uint8).reshape(28, 28)
label = int(row["label"])
```

#### MNIST as JPEG / 文件夹分类

典型目录：`train/0/00001.jpg` …  
逐文件 `preprocess_upload_path` 或打包为 PNG 走 HTTP 上传。

### 4.4 NumPy / CSV 通用

| 文件形态 | 形状 | 转换 |
|----------|------|------|
| `(28, 28)` uint8 | 单图 | 直接 `preprocess_uint8_28x28` |
| `(784,)` 或 `(1, 784)` | 展平 | `.reshape(28, 28)` |
| `(N, 28, 28)` | 批量 | 循环单图处理，**禁止** batch min-max |
| `(N, 784)` | Kaggle 型批量 | `reshape(N, 28, 28)` 后逐图 |
| `(1, 28, 28)` float 已 /255 | 误用 | 需还原 uint8 或走训练栈，勿与 client 流水线混用 |
| `(1, 1, 32, 32)` 已 pad | legacy | ❌ 与 client pad 语义冲突 |

### 4.5 官方 IDX（LeCun / torchvision）

| 文件 | 内容 |
|------|------|
| `train-images-idx3-ubyte` | 60000×28×28 uint8 |
| `train-labels-idx1-ubyte` | 60000 标签 |
| `t10k-images-idx3-ubyte` | 10000×28×28 uint8 |
| `t10k-labels-idx1-ubyte` | 10000 标签 |

魔数：`0x00000803`（图像）、`0x00000801`（标签）。  
本仓库 **不解析原始 IDX 文件**，统一经 `torchvision.datasets.MNIST` + `official_mnist.py`。

## 5. 上传元数据 JSON 契约

`POST /data/upload/preprocess` 与 `data/uploads/{uuid}/meta.json` 字段：

```json
{
  "source": "upload",
  "upload_id": "uuid",
  "filename": "digit.png",
  "label": null,
  "mnist_index": null,
  "input_digest_hex": "64位十六进制",
  "preview_png_base64": "原始28×28预览PNG",
  "fixed_shape": [1, 1, 32, 32],
  "stored_at": "ISO8601 UTC（仅服务端落盘）"
}
```

官方 MNIST 响应：`source: "official"`，`mnist_index` / `label` 有值，`upload_id` 为 `null`。

## 6. 禁止与废弃数据源

| 路径 / 格式 | 原因 |
|-------------|------|
| `scripts/prepare_mnist_network_a.py` 产物 | 与官方 IDX 流水线不一致 |
| `vpin-backend/data/mnist/*.npy` | 历史缓存，非 SSOT |
| `src/cnn_networks/image_mnist_32_32.npy` | 32×32 预 pad，跳过 client pad 步骤 |
| Batch 全局 min-max | 违反 per-image 论文语义 |
| 非灰度且不 resize 的原图 | 拓扑要求 28×28 灰度 |
