# vPIN 开发环境配置（最小可运行）
  
> 远程仓库：`https://github.com/blackdesert5410/vds-vpin.git`（SSH：`git@github.com:blackdesert5410/vds-vpin.git`）

## 1. 版本（必须）

| 组件 | 基线 | 兼容 | 备注 |
|------|------|------|------|
| Python | 3.11.7 | **仅 3.11.x** | 建 `.venv` 用这个 |
| Node.js | 22.22.0 | 18 / 20 / 22 | |
| Rust | stable 1.91.1 | stable ≥1.75 | `rustup default stable` |
| VS Build Tools | VS2022 C++ 桌面 | 含 MSVC | Tauri 必需 |
| Git | 2.40+ | 2.30+ | |

可选：CP-SNARK 另装 **仅** `nightly-2023-06-26`（勿设为 default）；OVDS 需 Docker Desktop。

手装链接：

- Python 3.11.7：https://www.python.org/downloads/release/python-3117/（勾选 Add to PATH）
- Node 22 LTS：https://nodejs.org/
- Rust：https://rustup.rs/ → 装完执行 `rustup default stable`
- VS Build Tools：https://visualstudio.microsoft.com/visual-cpp-build-tools/ → 勾选「使用 C++ 的桌面开发」
- Git：https://git-scm.com/download/win

装完**新开** PowerShell，确认：

```powershell
python --version   # Python 3.11.x
node --version     # v18/v20/v22
rustc --version    # 且 rustup default 为 stable
git --version
```

## 2. 从远程仓库初始化

```powershell
# 任选父目录
cd D:\WorkStation\pythoncode\experiment-reproduction

# HTTPS（无 SSH 钥时）
git clone https://github.com/blackdesert5410/vds-vpin.git vPIN-main
# 或 SSH
# git clone git@github.com:blackdesert5410/vds-vpin.git vPIN-main

cd vPIN-main
# 默认已在 main（origin/HEAD）。若跟当前开发线：
# git checkout feat-newovds
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

确认根目录有 `scripts\`、`start-ahe.ps1`、`vpin-backend\`。

## 3. 一键依赖 + BSGS + 预检 + 启动（MVP-AHE）

```powershell
# 在仓库根 vPIN-main\
.\scripts\setup.ps1
.\scripts\generate-bsgs-pickle.ps1   # ~30 分钟，只做一次
.\scripts\check-env.ps1              # 须无 [FAIL]
.\start-ahe.ps1                      # Python :8000 + Tauri 桌面
```

- 预训练权重已在 `model_training/outputs/`，无需先训练。
- 首次 UI 加载官方 MNIST 需联网（缓存到 `model_training/data/`）。
- 推理必须用 **Tauri 桌面端**，不要只开浏览器。

可选环境文件（一般可跳过）：

```powershell
copy .env.example .env
```

## 4. 按需（非跑通 AHE 必需）

### Rust 双引擎（:8001 / :8002）

需本地 `table.bin`（不进 Git）。有 CDN 时：

```powershell
$env:VPIN_ARTIFACTS_BASE_URL = "https://your-cdn/vpin-artifacts/v0.1.0"
.\scripts\pull-runtime-artifacts.ps1
```

或拷贝有效文件到 `vpin-client\tests\fixtures\table.bin`，然后：

```powershell
.\scripts\build-rust-ahe.ps1
.\scripts\start-rust-ahe.ps1 -Both
# 或三引擎：.\scripts\start-ahe-full.ps1
```

### OVDS（Docker）

```powershell
cd ovds-server
docker build -t vpin/ovds-reference:latest .
docker run --rm vpin/ovds-reference:latest
# 期望：charm BN254 ok
```

### vpin-console

```powershell
cd vpin-console
npm install
npm run dev              # 浏览器 mock
# npm run tauri dev      # 桌面
```

### CP-SNARK

```powershell
rustup toolchain install nightly-2023-06-26
cd src\cp-snark-full
rustup run nightly-2023-06-26 cargo test
```

## 6. 失败对照

| 现象 | 处理 |
|------|------|
| Python 不是 3.11 | 装 3.11.7，删 `.venv`，重跑 `setup.ps1` |
| 禁止运行脚本 | `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| 缺 `table.pickle` | `.\scripts\generate-bsgs-pickle.ps1` |
| MSVC / linker | 装 VS Build Tools「C++ 桌面」后重启 |
| Tauri 白屏 | 装 WebView2 Runtime |
| `discrete log not found` | 换有效 `table.bin` |
| nightly 搞坏 AHE | `rustup default stable` |
