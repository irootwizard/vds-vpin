泳道与参考图对照
  • 数据拥有者 → 客户端（预处理、承诺、配置）
  • 数据服务器 → 信任数据托管服务器（OVDS 存储）
  • 隐私控制器 → 密态方案治理（选型、隐私模式、门禁）
  • 区块链 → VADS/OVDS 可验证绑定（分片验签链，非公链）
  • 隐私控制平面 → 推理交互方 + 隐私五保证（明文域非线性）
  • 访问控制器 → 无头密态推理服务（P0–P6 编排、密文专属面）
  • 消费者 → 验证对象 + 客户端复核（VerificationReport）
