vPIN 三端交互示意图

平台由 客户端、信任数据托管服务器、无头密态推理服务 三角色构成； 数据面与控制面分离，托管链路与推理链路独立终结于 TLS。 依据顶层抽象架构、数据流图与隐私保护文档绘制。

图 1　vPIN 三角色拓扑、三条主链路（α 托管 / β 推理 / γ 服务间）与 P3 协作环

客户端

  • 用户明文预处理与密钥持有
  • 发起 P0–P2 与密态选型
  • 可作 inference_peer / verifier_target
  • 必收 VerificationReport 副本

信任数据托管服务器

  • VADS/OVDS 分片存储与验签
  • JWT + ACL 接入控制
  • hosted 模式数据入库主落点
  • 可代行 P3 非线性与 P6 验证

无头密态推理服务

  • 仅密文专属数据面
  • 线性层密态 / MPC 协议算子
  • 输出 witness、π，不可自证
  • 与托管链路 TLS 独立部署

交互载荷摘要

链路 方向 主要载荷 传输
α 托管面 客户端 → 托管 OVDS 分片、append_*、query/verify HTTPS TLS 1.2+
β 推理面 客户端 → 推理 P0–P2 控制消息、密文输入句柄、InputDigest HTTPS + WSS
β 推理面 推理 → 交互方 CiphertextPayload、TruncateRequest、密文回注 WSS TLS
γ 服务间 推理 ↔ 托管 绑定证明复核、ovds_verify_ref、代行 P3 密文 HTTPS / mTLS
P6 验证 验证对象 → 客户端 VerificationReport、证明工件、client_reverify HTTPS / 本地
