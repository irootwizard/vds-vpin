# 人脸识别完整实施计划

## 目标

扩展 vPIN 数据集支持从 MNIST/CIFAR-10 到人脸识别，提供 SimpleCNN 和 ResNet 两种模型，支持明文训练/推理，并为首个轻量模型接入 AHE 同态推理管线。

## 数据集

选用 LFW (Labeled Faces in the Wild)，通过 `torchvision.datasets.LFWPeople` 下载。

- 规模：13,233 张，5,749 个身份
- 过滤：取 top-K 身份（K=50），每身份 >= 10 张
- 图像：RGB，对齐裁剪到 64x64
- 存储：`model_training/data/lfw/`
- 下载命令：`python -c "from torchvision.datasets import LFWPeople; LFWPeople(root='./model_training/data/lfw', download=True)"`

## 模型

### SimpleCNN

架构（549K 参数，AHE 可行）：

```
Conv2d(3, 16, 3, pad=1) -> BN -> ReLU -> MaxPool2d(2)  # 64 -> 32
Conv2d(16, 32, 3, pad=1) -> BN -> ReLU -> MaxPool2d(2) # 32 -> 16
Conv2d(32, 64, 3, pad=1) -> BN -> ReLU -> MaxPool2d(2) # 16 -> 8
Flatten -> FC(4096, 128) -> ReLU -> Dropout(0.3) -> FC(128, K)
```

训练参数：AdamW, lr=1e-3, weight_decay=1e-4, CosineAnnealing, 50 epochs, batch_size=64

### ResNet18

从 `new_resnet/model.py` 导入，替换 `model.linear` 为 `nn.Linear(512, K)`。

训练参数：SGD, lr=0.01, momentum=0.9, weight_decay=5e-4, MultiStepLR([30,45], 0.1), 50 epochs, batch_size=64

## 实施步骤

### Phase 1: 数据集准备

1. 下载 LFW：`torchvision.datasets.LFWPeople`
2. 创建 `model_training/simple_cnn_face/dataset.py`：
   - `build_lfw_loaders(image_size, batch_size, top_k, min_samples, download)`
   - 过滤 top-K 身份，80/20 train/val split
   - 返回 `(train_loader, val_loader, num_classes, id_map)`

### Phase 2: SimpleCNN 明文训练

1. 创建 `model_training/simple_cnn_face/model.py`：`SimpleCNN(num_classes, dropout)`
2. 创建 `model_training/simple_cnn_face/train.py`：标准 PyTorch 训练循环
3. 训练并保存 checkpoint
4. 创建 `model_training/simple_cnn_face/export_weights.py`：
   - BN 折叠：conv_bn → W_fold, b_fold
   - 导出 `.npy`：`conv1_weight_16_3_3_3.npy` 等
   - 生成 `truncation_config.json`
5. 验证：`python -m model_training.simple_cnn_face.train --download --epochs 50`

### Phase 3: ResNet18 明文训练

1. 创建 `model_training/resnet_face/`：dataset 复用, model 导入
2. 训练并保存 checkpoint
3. BN 折叠 + `.npy` 导出（复用 new_resnet 的折叠逻辑）

### Phase 4: SimpleCNN AHE 管线接入

SimpleCNN 同态推理需要 5 轮交互（3 conv + 2 FC），适合 AHE。

**需要创建/修改的文件：**

| 文件 | 内容 |
|------|------|
| `vpin-client/crates/ahe-model-bundle/src/topology.rs` | `SIMPLE_CNN_FACE` 拓扑常量 |
| `vpin-client/crates/ahe-model-bundle/src/weights.rs` | `SimpleCNNFaceWeights` + 加载函数 |
| `vpin-client/crates/ahe-homomorphic/src/network_simple_cnn.rs` | conv + FC 同态操作（复用现有原语） |
| `vpin-client/crates/ahe-engine/src/engine_simple_cnn.rs` | 5 阶段状态机 |
| `vpin-client/vpin_client/hdc/data_adapters/face_rgb.py` | 64x64 RGB 人脸适配器 |
| `vpin-backend/data/models/registry.json` | 注册 `simple-cnn-face` |

**截断阶段设计：**

| Phase | Server | Client | Output Shape |
|-------|--------|--------|-------------|
| initial | encrypt input → server | — | [1,3,64,64] |
| after_conv1 | conv1(3→16) f=32 | decrypt,ReLU,MaxPool(2),shift→f=16 | [1,16,32,32] |
| after_conv2 | conv2(16→32) f=32 | decrypt,ReLU,MaxPool(2),shift→f=16 | [1,32,16,16] |
| after_conv3 | conv3(32→64) f=32 | decrypt,ReLU,MaxPool(2),shift→f=16 | [1,64,8,8] |
| after_fc1 | FC(4096→128) f=32 | decrypt,ReLU,shift→f=16 | [1,128] |
| after_fc2 | FC(128→K) | decrypt,argmax (logits_only) | [1,K] |

### Phase 5: 验证

```bash
# 明文推理
python -m model_training.predict face <image>

# AHE 推理 (Phase 4 完成后)
cargo run --release --bin ahe-cli -- infer --model simple-cnn-face --image face.jpg --crypto-backend ec
```

## 不在此次范围

- ResNet 人脸 AHE 推理（计算量过大）
- 人脸检测/对齐（MTCNN）—— 使用 LFW 预裁剪版本
- 1:N 检索 —— 先做 1:1 分类
